# Statistical Principles Define an Open-Source Differential Analysis Workflow for Mass Spectrometry Imaging Experiments with Complex Designs

## *Vignettes*

This repository contains a set of analysis vignettes accompanying *Statistical Principles Define an Open-Source Differential Analysis Workflow for Mass Spectrometry Imaging Experiments with Complex Designs* by Ethan B. T. Rogers<sup>1</sup>, Sai Srikanth Lakkimsetty<sup>1</sup>, Kylie Ariel Bemis<sup>1</sup>, Charles A. Schurman<sup>2</sup>, Peggi M. Angel<sup>3</sup>, Birgit Schilling<sup>2</sup>, and Olga Vitek<sup>1</sup>.

The links below contain reproducible code, in [R](https://cran.r-project.org), and outputs for each step of the proposed workflow. Datasets can be obtained via [0-Setup](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/0-Setup.html).

- [0-Setup](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/0-Setup.html)
- [1-Preprocessing](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/1-Preprocessing.html)
- [2-Filtering-Aggregation](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/2-Filtering-Aggregation.html)
- [3-Statistical-Modeling](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/3-Statistical-Modeling.html)
- [4-Statistical-Inference](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/4-Statistical-Inference.html)
- [5-Designing-Future-Experiments](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/5-Designing-Future-Experiments.html)
- [6-Mouse-Stroke-Case-Study](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/6-Mouse-Stroke-Case-Study.html)
- [Simulation-1](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/Simulation-1.html)
- [Simulation-2](https://vitek-lab.github.io/Workflow-CaseStudies-Statistical-Analysis-Differential-Abundance-MSI/Simulation-2.html)
